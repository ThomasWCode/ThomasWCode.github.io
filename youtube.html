An early internet project

YouTube Archive

A while after learning Lua, I made a channel called leopardbookshop to teach other people how to build things in Roblox Studio.

Visit the channel
No longer updated

Learning by explaining.

The videos mainly showed how to create common Roblox game features using Lua. Making tutorials forced me to understand each idea clearly enough to explain it, which turned out to be a very good way to learn.

I no longer publish new videos there—and I sound very young in the old ones—but I still really enjoyed making the channel. I later added a few Python videos as well.

400+subscribers reached
108,000+video views reached

Why keep it online?

Old work is still part of the story.

The presentation and my voice have changed a lot, but the channel captures the point where programming stopped being something I only did for myself and became something I could share with other people.
